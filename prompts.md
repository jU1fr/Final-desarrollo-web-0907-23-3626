# Prompts utilizados – Sistema de Reservas de Biblioteca

## Prompt 1. Creación del proyecto

Ayúdame a desarrollar una aplicación web para reservar salas de una biblioteca utilizando Node.js, Sequelize y SQLite en el backend, React básico en el frontend y sesiones mediante cookies.

La aplicación debe permitir iniciar sesión, mostrar las salas disponibles y crear reservas indicando sala, fecha, hora de inicio y hora de finalización. También debe evitar reservas con horarios solapados, manejar sesiones de 30 minutos de inactividad y redirigir al login cuando el servidor devuelva un error 401.

## Prompt 2. Estructura del backend

Ayúdame a organizar el backend utilizando Node.js, Express, Sequelize y SQLite. Necesito manejar los modelos de usuarios, salas y reservas, establecer sus relaciones y crear las rutas necesarias para el funcionamiento del sistema.

## Prompt 3. Desarrollo del frontend

Ayúdame a crear una interfaz sencilla en React para el sistema de reservas de biblioteca. Debe incluir un formulario de inicio de sesión, un listado de salas, un formulario para crear reservas y una tabla para visualizar las reservas registradas.

## Prompt 4. Ejecución del proyecto

Explícame paso a paso cómo ejecutar el backend y el frontend desde Visual Studio Code, incluyendo los comandos necesarios para instalar las dependencias, iniciar Node.js y ejecutar React con Vite.

## Prompt 5. Solución de errores

El servidor de React inicia correctamente, pero al abrir la aplicación en el navegador solamente aparece una pantalla blanca. Ayúdame a identificar el problema utilizando la consola del navegador y a corregirlo sin afectar las demás funcionalidades.

## Prompt 6. Corrección del componente React

En la consola del navegador aparece el error `Uncaught ReferenceError: React is not defined` dentro del archivo `App.jsx`. Explícame por qué ocurre y cómo solucionarlo para que la interfaz funcione correctamente.

## Prompt 7. Mejora del diseño visual

La aplicación ya funciona correctamente, pero el frontend tiene un diseño muy básico. Necesito un CSS más moderno y profesional, con colores adecuados, formularios organizados, botones atractivos, una tabla de reservas y un diseño adaptable a diferentes pantallas, sin modificar la lógica del sistema.
