# Prompts utilizados / registro de ayuda de IA

1. **Solicitud inicial:** "Vamos a construir esta web app siguiendo las instrucciones; paso a paso y de forma rápida. No necesita un diseño complejo. Usar una base de datos sencilla como SQLite." 
2. **Solicitud para la segunda serie:** "Ahora la serie 2 en Visual Studio Code."
3. **Alcance de la ayuda recibida:** aplicación de biblioteca con backend Node.js + Express + Sequelize + SQLite, frontend React, login con sesión en cookie, expiración después de 30 minutos de inactividad, validación de reservas que se cruzan en el backend y redirección visual al login tras 401.

Se revisaron los modelos, la condición de solapamiento y las pruebas descritas en README.md. Este registro se puede ampliar con nuevos prompts concretos que se utilicen durante la resolución.
